# Библиотечная система LibraryDB

Учебный проект по разработке базы данных для учёта читателей, книг и операций выдачи и возврата книг.

**Автор:** Зюбина Полина

## Описание

База данных `LibraryDB` предназначена для автоматизации работы библиотеки. Система позволяет вести каталог книг и читателей, искать книги по названию или библиотечному шифру, регистрировать выдачу и возврат книг, а также получать справочную информацию.

Проект выполнен в Microsoft SQL Server 2014 с использованием языка T-SQL. Для запуска и проверки скриптов используется SQL Server Management Studio (SSMS).

## Возможности

- добавление читателей и книг;
- поиск книг по части названия или библиотечного шифра;
- проверка количества доступных экземпляров;
- выдача книги читателю при наличии свободного экземпляра;
- регистрация возврата книги;
- автоматическое изменение количества доступных экземпляров с помощью триггеров;
- просмотр доступных книг и текущих выдач через представления;
- получение отчётов о выданных и возвращённых книгах за период;
- просмотр книг, находящихся у конкретного читателя.

## Структура базы данных

В базе данных используются три таблицы:

| Таблица | Содержимое |
|---|---|
| `Readers` | ФИО читателя, номер читательского билета и дата его выдачи |
| `Books` | Название, авторы, библиотечный шифр, год и место издания, издательство, общее и доступное количество экземпляров |
| `Loans` | Какая книга и кому выдана, дата выдачи, плановая и фактическая даты возврата |

Связи:

- `Readers (1) — (N) Loans`
- `Books (1) — (N) Loans`

ER-диаграмма находится в файле `диаграмма.docx`.

## Проверка работы

В `client_script.sql` последовательно проверяются основные операции:

1. добавление нового читателя и книги;
2. поиск книг по названию и библиотечному шифру;
3. выдача книг;
4. просмотр доступных книг через представление;
5. проверка книг у читателя;
6. проверка наличия конкретной книги;
7. возврат книги;
8. повторная проверка доступных экземпляров;
9. отчёты о выданных и возвращённых книгах;
10. просмотр текущих выдач.

Для проверки сохранения истории можно выполнить:

```sql
USE LibraryDB;
GO

SELECT * FROM dbo.Loans ORDER BY LoanID;
GO

SELECT BookID, Title, TotalCopies, AvailableCopies
FROM dbo.Books
ORDER BY BookID;
GO
```

При успешной выдаче в `Loans` появляется строка, а `AvailableCopies` уменьшается. После возврата строка в `Loans` сохраняется, в `ReturnDate` проставляется дата, а `AvailableCopies` увеличивается.

## Основные объекты базы данных

### Хранимые процедуры

| Процедура | Назначение |
|---|---|
| `sp_AddReader` | Добавление нового читателя |
| `sp_AddBook` | Добавление книги в каталог |
| `sp_IssueBook` | Выдача книги при наличии свободного экземпляра |
| `sp_ReturnBook` | Регистрация возврата книги |
| `sp_SearchBooks` | Поиск по части названия или библиотечного шифра |
| `sp_CheckAvailability` | Проверка количества доступных экземпляров |
| `sp_GetIssuedBooks` | Выданные книги за указанный период |
| `sp_GetReturnedBooks` | Возвращённые книги за указанный период |
| `sp_GetReaderBooks` | Книги, которые находятся у указанного читателя |

### Представления

| Представление | Назначение |
|---|---|
| `vw_AvailableBooks` | Книги, доступные в наличии |
| `vw_CurrentLoans` | Текущие выдачи, то есть книги на руках у читателей |

### Триггеры

| Триггер | Назначение |
|---|---|
| `trg_IssueBook` | Уменьшает `AvailableCopies` при выдаче книги |
| `trg_ReturnBook` | Увеличивает `AvailableCopies` при возврате книги |
